# RewardsFarm-BEYOND

Repositório inicializado para armazenar arquivos e versões do projeto.

## Como enviar arquivos pelo navegador

1. Abra a página do repositório: https://github.com/micaeljviana9-eng/RewardsFarm-BEYOND
2. Entre em **Add file → Upload files**.
3. Selecione ou arraste os arquivos para a página.
4. Informe uma mensagem de commit e clique em **Commit changes**.

Você pode enviar até 100 arquivos por vez pela interface web. O limite da interface web é de 25 MiB por arquivo; pela linha de comando, arquivos de até 100 MiB podem ser enviados. Arquivos maiores exigem Git LFS ou outra forma de armazenamento. Consulte a documentação oficial: https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository

## Enviar pelo celular

Abra o repositório no navegador, ative **Site para computador** se necessário e procure **Add file → Upload files**. Se essa opção não aparecer no aplicativo do GitHub, use o navegador.

## Segurança

Não envie senhas, tokens, chaves de API, arquivos `.env` ou dados pessoais. Para arquivos grandes, prefira Git LFS ou Releases conforme o uso.

## Estado atual

Este README inicializa o repositório; adicione os arquivos do projeto usando as instruções acima.
